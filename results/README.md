# Results

- `figures/`: the data figures of the paper, drawn by notebook section 23 from the saved results.
- `paper_numbers_final.txt`: every verdict (guarantees G, findings X) and headline number of the final paper run.
- `s25_bdd_paper.json`, `s16d_v11_bdd.json`: BDD-OIA results (sections 16d and 25).
- `runtime.json`: CPU time of brackets and pairwise certificates (section 23).

Trained heads, cached features and all intermediate checkpoints of the paper run are stored on Hugging Face at `APassionateResearchers/NeSyCVPR`, and the BDD-OIA frames used here at the dataset `APassionateResearchers/bdd-oia`; both will be made public with the paper.
